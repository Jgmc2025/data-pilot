# Dados de vendas

`sales.csv` é uma amostra sintética criada a partir dos campos, categorias, produtos, cidades, canais e status visíveis no material da aula. Ela permite executar o projeto; não é o arquivo original disponibilizado pelo Expert.

Para gerar novamente a amostra, execute na raiz do repositório:

```powershell
python scripts/generate_sales_data.py
```

Se você obtiver o CSV original das aulas, coloque-o como `data/sales.csv`. O preparo aceita os nomes de colunas em português mostrados no print.
